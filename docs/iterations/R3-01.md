## 实现与证据

完整检查得到 **92 passed**，其中 88 项来自 R2 套件，新增三项 Streamlit AppTest 和一项数据库升级检查。依赖、静态和格式检查通过。[完整测试记录](../evidence/R3-01/local-check.log)

- 登录用预置账户和带独立盐值的 scrypt 密码摘要。用户身份来自密码校验，服务层逐次核对账号有效性、角色和订单归属。退出会清空浏览器会话内的用户状态。
- 客户可以从有效目录下单，查看自己的订单、备注和历史。工作人员可以查看队列，按当前阶段执行下一步。按钮提交时带上工作人员当时看到的版本，两人同时操作时旧页面收到刷新提示。
- 新迁移添加密码校验表。原 R2 迁移保留，迁移测试从含有真实订单历史的 R2 数据结构升级并重读。T19 的预期迁移记录已更新为两个明确的迁移文件名。
- Streamlit AppTest 在真实 PostgreSQL 上覆盖创建、换账号、停用账号、失败登录、旧页面提交和交付界面。AI 还使用独立 Chrome 会话完成下单与制作，观察到客户可领取、工作人员可确认交付、另一位客户列表为空。[浏览器实测](../evidence/R3-01/browser.log)
- 本轮运行于这台 Mac，数据保存在专用本机 PostgreSQL。GitHub 远程运行、公开部署和外部用户任务观察尚待取得证据。当前验收针对本地候选版本。
