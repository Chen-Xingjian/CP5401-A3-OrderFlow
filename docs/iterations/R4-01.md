# R4-01 单页角色演示及 V1.0 发布核验

学生批准了 R3 的交付行为，并决定在 V1.0 前调整账号交互。老师 CampusConnect 示例采用角色选项和角色内用户选择器。OrderFlow 保留自己的订单流程与 PostgreSQL，允许在同一个页面扮演 Alex、Blair、Sam 和 Taylor。能打开应用的访客也能选择工作人员，演示库只放虚构资料。

| 核验项目 | 证据 |
|---|---|
| 本轮实现与回归 | 见本轮 PR 的差异和质量检查，覆盖同角色换人、角色切换、客户订单隔离、过期操作和交付历史。 |
| 云端地址、部署版本与持久性 | 待获得 Streamlit 工作区访问及专用 PostgreSQL 连接后实测。 |
| 人工验收 | 云端验证完成后由学生亲自判断并决定是否通过。 |

人工场景围绕一张虚构订单。在同一页面用 Alex 下单，切换 Blair 检查可见范围，再由 Sam 处理至待领取，Taylor 在交付后确认。返回 Alex 查看最终状态与历史。学生判断谁可以看见订单、能否分清待领取和已交付，以及历史能否辨认实际操作的工作人员。本轮不实施 CR001。
